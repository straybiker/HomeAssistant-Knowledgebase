# Contributing

Found an issue? Have a better calibration formula for WH52? Submit an issue or pull request!

## Process

1. Fork the repository
2. Create a branch: `git checkout -b guides/improvement`
3. Make changes and test
4. Commit with clear messages
5. Push and open a Pull Request

## What We Welcome

- Guide improvements and clarifications
- Bug fixes in scripts
- New guides for other RTL-433 devices
- Better calibration values
- Troubleshooting tips

## Questions?

Open an issue or check existing discussions.

Thank you for contributing! 🏠✨
